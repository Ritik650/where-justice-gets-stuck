# Data licence

The code in this repository is under the MIT licence (see `LICENSE`). The data is not.

## Derived from Development Data Lab data

Everything in `data/mart/` and `outputs/` is derived from the Development Data Lab eCourts data and carries the same licence: **[CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/)**.

- **Attribution:** credit Development Data Lab and cite the paper below.
- **Non-commercial:** no commercial use. A commercial licence has to come from Development Data Lab (info@devdatalab.org).
- **Share-alike:** anything built from these tables goes out under the same licence.

> Ash, E., Asher, S., Bhowmick, A., Bhupatiraju, S., Chen, D., Devi, T., Goessmann, C., Novosad, P., and Siddiqi, B. (2025). "In-Group Bias in the Indian Judiciary: Evidence from 5 Million Criminal Cases." *The Review of Economics and Statistics*. DOI: 10.1162/rest_a_01569.

The archive's own `license.txt` is the Open Database License (ODbL) v1.0, which differs from DDL's data page. This project follows the page's stricter terms. A copy of the archive's text is in [docs/ddl_license_in_archive.txt](docs/ddl_license_in_archive.txt). Ask Development Data Lab before any commercial use.

The raw data and row-level Parquet are not in this repository. `pipeline/download_ddl.py` fetches the raw data from Development Data Lab's own link.

The eCourts case number (`cino`) is dropped at load, so nothing here links back to a named court record. Issue-log samples use only the ID generated by Development Data Lab.
