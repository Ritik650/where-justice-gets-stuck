# Data manifest

Generated by `make manifest` from [data/manifest.json](manifest.json). Every file this project reads, with sizes and hashes,
so a rebuild can prove it used the same inputs.

## Case data

**Source:** Development Data Lab, [judicial data](https://www.devdatalab.org/judicial-data): eCourts case records filed 2010-2018 (CSV copies only),
CC BY-NC-SA 4.0 (see [DATA_LICENSE.md](../DATA_LICENSE.md)).
**Downloaded:** 2026-11-17 by `pipeline/download_ddl.py`, which streams the
5.1 GB Dropbox archive (https://www.dropbox.com/sh/hkcde3z2l1h9mq1/AADRe-BuBQ92ozAJiG7YERdCa?dl=1) and keeps only the CSV members, checking each one's size and CRC-32.

which stops if a file on disk differs in size from the download's record.
